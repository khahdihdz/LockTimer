Android permissions

What does LockTimer need?

  • Device Admin — required to perform the screen-lock action.
  • Notifications — shows the remaining countdown (Android 13+).
  • Exact alarms — provides a scheduled fallback (Android 12+).
  • Battery optimization exemption — helps prevent the system from delaying background work.

Permissions are requested by Android. Device Admin is used only to lock the screen.

FAQ

Good to know before you install.

Does LockTimer contain ads?

No. The app is ad-free and does not integrate Google Mobile Ads or another advertising SDK.

Why is Device Admin required?

Android requires this permission for an app to lock the device screen. LockTimer uses it only for that action.

Will the timer work with the screen off?

Yes. The countdown runs in a foreground service. Some device manufacturers may require you to allow background activity or unrestricted battery usage.

What if I use Xiaomi, OPPO, or vivo?

Check your system's battery and auto-start settings for LockTimer. Set background activity to unrestricted if your device stops background services aggressively.

How do I change the app language?

LockTimer supports Vietnamese and English. On Android 13 or later, change it in Settings → Apps → LockTimer → Language. On earlier versions, use your device language.

How are updates delivered?

The app checks the latest GitHub Release and shows an in-app update prompt when a newer APK is available.
